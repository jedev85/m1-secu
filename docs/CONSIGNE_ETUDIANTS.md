# Consigne de rendu

Vous auditez une application Symfony interne volontairement vulnerable, uniquement en local.

## 1. Methodologie d'audit

Votre methodologie doit presenter: cadrage, perimetre, hypotheses, cartographie, analyse des roles, choix des tests, limites, outils utilises et priorisation.

## 2. Documentation technique

Documentez l'architecture, les entites, les routes, les roles, les flux sensibles, les surfaces d'attaque, les dependances et la configuration.

## 3. Rapport de pentest

Pour chaque vulnerabilite: identifiant, titre, criticite, famille OWASP, description, prerequis, etapes de reproduction, preuve, impact metier, cause racine, recommandation et reference eventuelle.

## 4. Plan de remediation

Le plan doit couvrir: quick wins, corrections critiques, court terme, moyen terme, long terme, dette technique, priorisation et dependances entre corrections.

## 5. Cinq exemples de correction

Pour chaque correction: vulnerabilite ciblee, extrait vulnerable, explication, extrait corrige, justification, test de validation et risque residuel.

## 6. Soutenance

Preparez une presentation courte: contexte, methode, principaux risques, priorites de correction et arbitrages techniques.
