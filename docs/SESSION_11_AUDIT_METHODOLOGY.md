# Session 11 - Méthodologie audit

## Objectifs pédagogiques
Structurer une démarche d'audit applicatif exploitable.

## Contexte
Les étudiants préparent l'audit final.

## Notions abordées
Périmètre, hypothèse, preuve, criticité, remédiation, restitution.

## Parcours dans l'application
Choisir deux modules et appliquer la même méthode.

## Exercices étudiants
N1: définir périmètre. N2: construire checklist. N3: qualifier constats. N4: relire un rapport pair. N5: fiche finale.

## Indices progressifs
Utiliser `FINAL_AUDIT_SUBJECT.md`.

## Points de vigilance
Éviter les affirmations sans preuve.

OWASP Testing Guide, ASVS, CWE.
