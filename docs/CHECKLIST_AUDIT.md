# Checklist d'audit

- Installer et reinitialiser la base.
- Lister les roles et comptes.
- Cartographier les routes HTML.
- Cartographier les endpoints API.
- Identifier les actions qui modifient l'etat.
- Comparer les controles visibles dans Twig et les controles serveur.
- Tester les changements d'identifiants dans les URL.
- Tester les formulaires avec donnees inattendues.
- Tester les imports, exports, uploads et telechargements.
- Tester la recherche et les tris.
- Examiner les logs, parametres et fichiers de configuration.
- Verifier les donnees exposees par l'API.
- Documenter les preuves avec etapes reproductibles.
- Prioriser les risques.
- Rediger les recommandations et corrections.
