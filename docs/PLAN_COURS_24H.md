# Plan de cours 24h

## Seance 1 - Prise en main, cadrage et cartographie

Objectifs: comprendre le contexte, installer le projet, explorer l'application, cartographier roles, routes et flux, identifier les premieres hypotheses.

Production: cartographie fonctionnelle, surfaces d'attaque, strategie d'audit.

## Seance 2 - Authentification, autorisation, IDOR, API

Objectifs: tester les roles, comparer interface et serveur, tester IDOR, auditer les endpoints API, documenter les ecarts.

Production: 3 vulnerabilites documentees minimum.

## Seance 3 - Injections, XSS, CSRF, validation serveur

Objectifs: tester les entrees utilisateur, rechercher XSS, tester injections, tester CSRF, analyser formulaires sensibles.

Production: 3 vulnerabilites documentees minimum.

## Seance 4 - Fichiers, uploads, SSRF, configuration, secrets

Objectifs: tester uploads, acces fichiers, SSRF, logs, configuration et fuites d'information.

Production: 3 vulnerabilites documentees minimum.

## Seance 5 - Rapport, criticite, remediation, corrections

Objectifs: structurer le rapport, prioriser les risques, rediger le plan de remediation, produire les corrections, ajouter des tests de validation.

Production: brouillon complet, 5 corrections detaillees.

## Seance 6 - Finalisation, revue croisee et soutenance

Objectifs: finaliser les livrables, relire les preuves, ameliorer les recommandations, preparer et presenter la soutenance.

Production: rapport final, plan de remediation, soutenance.
